## 4. 그래픽 "인디 탈출" — 외부 에셋 0개로 그럴듯하게 연출하기

모든 시각 효과는 외부 3D 모델이나 2D 이미지 없이 `render` 단계의 코드로 직접 생성합니다.

| 기법 | 기대 효과 | 핵심 구현법 |
|------|-----------|-------------|
| **블롭 그림자 (Blob Shadow)** | 유닛이 바닥에 입체감 있게 붙어 보임 | 유닛 발밑에 방사형 타원 그라디언트 렌더링 |
| **블룸 (Bloom)** | 빛나는 발광(Emissive) 요소 연출 | 가산 합성 및 임계값 블러 패스 적용 |
| **절차적 텍스처** | 1장의 기본 텍스처 + 팔레트 조합 | 그레이스케일 노이즈 × 색상 팔레트 연산 |
| **파티클 풀 (Particle Pool)** | 타격, 폭발, 화염 이펙트 | 메모리 할당 없는 고정 배열 재사용 |
| **데미지 숫자 풀** | 타격 피드백 제공 | Canvas fillText, 상단 이동 후 페이드아웃 |
| **카메라 셰이크** | 피격 및 타격감 전달 | cumulative shock → 제곱 감쇠 연산 |
| **비네트 & 안개** | 공간 깊이감 제공 | 시야 거리 기반 안개 밀도 조절 |
| **절차적 캐릭터** | 로우폴리 3D / 2D 지오메트리 | 프리미티브 조합 + 투구, 지팡이 등 직업 소품 |

```js
// 카메라 셰이크: 피격/타격 시 누적 후 제곱 감쇠
addShake(v) { this.shake = Math.min(0.8, this.shake + v); }
// 프레임 업데이트:
this.shake = Math.max(0, this.shake - dt * 1.7);
const s2 = this.shake * this.shake;
cam.position.x += (Math.random() - 0.5) * s2 * 2.2;
```

### 4.1 조명, 실시간 그림자 및 톤매핑

1. **실시간 그림자:** 방향광(Directional Light) 1개 + PCFSoft 섀도맵을 사용하되, 섀도 카메라 범위를 유닛이 움직이는 전장 공간에만 타이트하게 맞춥니다.
2. **필름 톤매핑:** ACESFilmic 톤매핑을 적용하여 너무 밝은 파티클이나 발광체가 흰색 덩어리로 뭉개지는 현상을 방지합니다.
3. **그림자 생성 검증:** 픽셀 차분(`readPixels`)으로 그림자 켜짐/꺼짐 시 1% 이상의 픽셀 변화가 발생하는지 자동 검사할 수 있습니다.

### 4.2 화면에 보이지 않는 요소 배제하기

탑다운/쿼터뷰 카메라 각도상 화면 바깥에 위치하는 하늘 돔이나 먼 배경 요소는 아예 렌더링 리스트에서 제외하는 것이 좋습니다.

```js
// 카메라 절두체(Frustum) 바깥의 구름/배경 객체는 생성 생략
const v = obj.position.clone().project(camera);
// |v.x| < 1 && |v.y| < 1 && v.z < 1 판정을 벗어나면 스킵
```

또한, 게임을 구동한 지 4초 후 FPS를 실측해서 45fps 미만인 저사양 기기라면 블룸 이펙트와 파티클 수를 줄이는 가벼움(Lite) 모드로 자동 전환하는 로직을 갖춥니다.

### 4.3 외부 이미지 텍스처 적용 시 색상과 질감 분리

외부 이미지 텍스처를 적용할 때는 사진 본연의 색을 그대로 쓰는 컬러맵(`map`) 방식과, 요철/질감만 빌려오는 둠맵(`bumpMap`) 방식을 구분해야 합니다.

- **색상이 중요한 표면(나무, 흙):** `map` 활용
- **이미 색상이 지정된 고유 요소(기와, 무늬 벽):** `bumpMap`만 씌워 요철감만 살림
- **스타일라이즈드 텍스처:** 납작한 컬러면에 실사 사진을 얹으면 어색해지므로 무분별한 텍스처 덧씌우기는 지양

### 4.4 연사 공격 시 카메라 셰이크 대신 위치 기반 임팩트 활용

자동 조준이나 연타 공격이 발생하는 게임에서 평타 명중 시마다 카메라 셰이크를 발생시키면 화면이 지속적으로 흔들려 멀미를 유발합니다.

이럴 때는 전체 카메라 좌표를 흔드는 대신, 맞은 위치 좌표에 충격 파동 이펙트(`ripple(x, z, power)`)를 터뜨리는 편이 시각 전달력과 안정성 면에서 훨씬 우수합니다.

### 4.5 모바일 기기에서의 시야각 및 장식 최적화

모바일 기기에서는 조작 화면이 협소하므로 배경 장식(바람 잔디, 해변)을 생략하고 화각을 넓혀 전장 면적(터치 영역)을 확보해 주는 설계가 유용합니다. `pointer: coarse` 매치 쿼리로 모바일 기기를 감지하여 초기 부팅 시부터 저사양 옵션을 기본 적용합니다.
