## 8. AI 협업 프롬프트 패턴 (실전 활용 지시문)

| 패턴 | 지시 예시 | 패턴의 효과 및 비고 |
|------|-----------|---------------------|
| **증상 중심 전달** | "이동 조작이 후반으로 갈수록 뻑뻑한 느낌이야. 증가량을 1/10로 줄이거나 곡선을 바꿔봐." | 원인 진단과 해결책 도출을 AI에게 일임 |
| **자율 위임형** | "네가 이제 심사위원이 되어서 게임에 빠진 추가 기능을 스스로 찾아내 구현해봐." | 미니맵, 콤보 연출, 진동 피드백 등을 AI가 자율 발굴 |
| **경쟁작 리뷰 분석** | "유사 장르 히트작 리뷰에서 재미 요소를 분석하고 우리 게임에 빠진 걸 진단해줘." | 전설 진화 특성 시스템의 아이디어를 도출 |
| **레퍼런스 이식** | "기존 저장소 X를 참고해서 전반적인 그래픽/사운드 퀄리티업 패스를 적용해줘." | 검증된 패턴을 신규 장르나 스택으로 이식 |
| **규칙 문서 승격** | "이번에 확정한 세계관/아키텍처 규약을 CLAUDE.md에 추가해줘." | 세션이 초기화되어도 개발 컨텍스트 일관성 유지 |
| **상시 스케줄링 위임**| "매일 아침 관련 게임, 신작, 오픈소스 소식을 조사해 추천 리스트를 정리해줘." | 일회성 조사를 **매일 구동되는 자동화 루프**로 승격 |
| **순차 실행 요청** | "한 번에 다 하지 말고 순서대로 하나씩 진행하며 검증해줘." | 실패 원인이 혼재되지 않도록 단계별 실측 및 검증 유도 |
| **다중 에이전트 감사**| "모든 UI/게임 경로를 N개 에이전트가 감사하고 교차 반증된 항목만 수정해줘." | 오탐을 교차 검증으로 거르고 실제 버그만 선별 해결 |

### 8.1 텍스트 중심 검증 증거 남기기 (터미널 SVG)

검증 결과를 저장소에 기록할 때 스크린샷 이미지(PNG/GIF) 대신, 테스트 커맨드의 stdout 출력을 **터미널 형태의 SVG 벡터 파일**로 생성해 문서에 첨부하면 용량이 획기적으로 줄어들고 `git diff`로 변경 사항을 손쉽게 추적할 수 있습니다.
