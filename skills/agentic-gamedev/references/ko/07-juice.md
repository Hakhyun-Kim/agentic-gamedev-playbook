## 7. 게임필(Juice) & 조작성 체크리스트

적은 구현 노력으로 게임의 완성도와 손맛을 비약적으로 끌어올리는 팁 모음입니다.

- [ ] **잔상 체력바:** 피격 시 메인 HP바는 즉시 줄고, 뒤의 황색 잔상 바가 0.5초 지연 후 부드럽게 감소
- [ ] **히트 플래시 (Hit Flash):** 피격 시 유닛 순간 순백색 틴트 + 미세 스케일 업
- [ ] **콤보 팝:** 스프링 애니메이션(`cubic-bezier`)으로 튀어나오는 콤보 수치 UI
- [ ] **화면 피격 연출:** 플레이어/본진 피격 시 화면 테두리에 붉은 비네트 플래시
- [ ] **저체력 맥동 & 심장박동음:** 사운드와 visual pulse 동기화
- [ ] **상승 텍스처 (Damage Float):** 데미지/획득 자금 수치가 위로 떠오르며 페이드아웃
- [ ] **사거리 가이드 & 미리보기:** 사거리 표시 링, 다음 웨이브 유닛 구성 예고, 보스 HP 바
- [ ] **최초 1회 코치 팁 (Coach Chips):** 직관적 안내 칩 + 즉시 시작 버튼
- [ ] **결과 공유 카드:** Canvas 렌더링 기반 결산 스크린샷 다운로드/공유 기능

### 7.1 피드백 시스템의 일원화

이벤트 오디오, 시각 팝업, 알림 메시지는 개별 기능 코드에 인라인으로 흩뿌리지 말고, 이벤트 디스패처나 액션 큐 등 **중앙 통로 한 곳**에 통합하여 부착합니다.

### 7.2 키보드 및 예측형 UI 규칙

1. **키보드 중심 조작:** Enter(확인), Space(주 액션), Esc(취소/닫기), 방향키/Tab(타겟 전환), 숫자키(선택) 등 표준 바인딩 지원.
2. **단일 후속 행동 자동 진행:** 결과 노출 후(0.8~1.2초) 클릭 없이 자동 다음으로 넘어가 조작 피로 감소. (단, 실패 시에는 사유 확인을 위해 자동 진행 생략)
3. **입력창 포커스 이탈 대비:** 전역 핸들러에서도 주 액션을 수신할 수 있도록 설계하되 `ev.isComposing`(한글 입력 상태) 유무를 정확히 판별.

### 7.3 터치 기기 감지 및 레이아웃 최적화

- User-Agent 파싱 대신 `matchMedia('(pointer: coarse)')` 미디어 쿼리를 사용해 모바일/터치 입력을 정밀하게 구분합니다.
- 모바일 가상 조이스틱 생성 조건과 UI 지침 문구를 동일한 미디어 쿼리 변수로 관리하여 불일치를 방지합니다.
