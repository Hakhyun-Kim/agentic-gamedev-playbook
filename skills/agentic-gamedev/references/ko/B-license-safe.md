## 부록 B. 라이선스 안전성 (License-Safe Rules)

외부 자산 및 라이브러리 반입 시 라이선스 사고를 구조적으로 방지하기 위한 원칙과 체크리스트입니다.

### B.1 외부 자산 반입의 기본 원칙

- **기본 원칙:** 이미지/사운드는 코드로 직접 생성(Procedural generation)하는 것을 기본으로 유지합니다.
- **반입 허용 기준:** 외부 자산을 도입할 경우 "원장(`assets.json`) 없는 반입 금지" 정책을 엄격히 적용합니다.

### B.2 애셋 종류별 반입 정책

| 종류 | 정책 | 사유 및 비고 |
|------|------|--------------|
| **폰트 (Font)** | OFL/CC0 라이선스만 허용 | `CREDITS.md` 명시 + 시스템 폰트 폴백 필수 |
| **그래픽 (3D/2D)** | 허용하되 아트 스타일 통일 우선 | 스타일 파편화로 인한 비주얼 조잡화 방지 |
| **사운드 (Audio)** | BGM은 코드 합성 유지, 단발 효과음만 반입 허용 | 효과음은 실사 반입이 가성비 최고이며 BGM은 동적 변주에 합성이 필수적임 |

### B.3 라이선스 원장 (Ledger) 4대 규칙

1. **기계가 읽을 수 있는 파일로 원장 작성 (`assets.json`):** 출처 URL, 저작자, 라이선스 명시 후 `CREDITS.md` 자동 생성.
2. **원본 바이너리는 수정 없이 보관:** 게인/피치 조절 등은 코드에서 실행하여 원본 체크섬 검증 유지.
3. **`npm run assets` CLI로 반입 검증:** 원장 기반 지문 대조 자동화.
4. **폴백(Fallback) 보장:** 파일 404/로드 실패 시에도 시스템 폰트나 합성음으로 안전하게 폴백되도록 설계.
