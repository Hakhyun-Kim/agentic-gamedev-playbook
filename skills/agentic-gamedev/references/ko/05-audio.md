## 5. 사운드 — 외부 오디오 파일 0개로 구현하는 Web Audio 합성

게임 내 모든 효과음과 BGM을 외부 오디오 파일 없이 Web Audio API 기본 합성 코드로 구현합니다.

### 5.1 사운드 합성 원시 도구 (Primitive Tools)

```js
tone(freq, start, dur, type, vol, glideTo)  // 오실레이터 1개 + 게인 엔벨로프
noise(start, dur, vol, freq, q)             // 화이트 노이즈 + 밴드패스 필터
```

위 두 가지 원시 함수를 조합해 효과음 레시피를 정의합니다.
- **성공:** 상승 아르페지오 (도-미-솔-도)
- **실패:** 부드러운 하강음 (오답 시 플레이어를 불쾌하게 하지 않도록 조율)
- **타격음:** 아주 짧은 밴드패스 필터드 노이즈 + 레이트 리밋 (45~70ms)
- **저체력 연출:** 심장 박동음 + 화면 붉은 맥동 이펙트

### 5.2 합성 BGM 구성을 위한 필수 6요소

단순 피치음 시퀀서가 삑삑거리는 기계음처럼 느껴지는 현상을 피하려면 아래 6가지 요소를 적용해야 합니다.

1. **코드 진행 (Chords):** 마디별 화성을 정의하고 트랙 전체가 코드 구성음 내에서 동작하도록 설계
2. **패드 (Pad):** 두 개의 톱니파를 ±6센트 디튠(Detune)하여 겹치고 로우패스 필터로 부드럽게 감싸는 방식
3. **아르페지오 (Arpeggio):** 코드 구성음을 인덱스 패턴(`[0,1,2,1,0,2...]`)으로 순회
4. **베이스 (Bass):** 근음 위주로 로우패스 처리
5. **드럼 (Drums):** 킥(사인 파형 150→48Hz), 스네어(노이즈), 하이햇(하이패스 노이즈) 구성
6. **리버브 (Reverb):** 피드백 딜레이 + 로우패스 필터를 이용한 가벼운 공간감 형성

### 5.3 음소거(Mute) 기능 설계의 필수 체크리스트

1. **BGM과 SFX의 개별 음소거 지원:** 사용자의 가장 흔한 요구나 BGM 단독 끄기를 고려할 것.
2. **HUD 상의 직관적인 토글 버튼:** 설정 메뉴 깊숙이 넣지 말고 HUD 상단에 아이콘+텍스트 조합으로 배치.
3. **음소거 상태의 영속성:** `localStorage`에 설정값을 캐싱.
4. **단축키(M) 지원:** 즉각적인 조작 편의성 제공.
5. **AudioContext 노드 차단 방식:** 오디오 컨텍스트를 닫지 않고 `if (muted) return;` 방식을 채택하여 복원 시 지연이나 상태 꼬임 방지.

### 5.4 오디오 마스터링: 리미터, 패닝, 피치 가변

- **리미터 (Limiter):** 여러 오디오 노드가 겹칠 때 발생하는 클리핑(치직거림) 방지 (`DynamicsCompressor` 노드 활용)
- **스테레오 패닝 (Stereo Panning):** 유닛의 전장 X 좌표를 `StereoPanner`(-0.85 ~ 0.85)에 연결
- **피치 가변 (Pitch Randomization):** 타격음 재생 시마다 ±40~90 cents 범위의 미세 피치 가변을 주어 반복 재생의 지루함 제거

### 5.5 지속음(Sustain SFX) 리소스 회수 처리

차지 샷이나 지속 빔처럼 키를 누르는 동안 계속 재생되는 오실레이터는 다음 3개 경로 전체에서 반드시 `stop()`을 호출해야 합니다.
1. 키/버튼 해제 시
2. 일시정지 또는 UI 오버레이 오픈 시
3. 씬/컴포넌트 언마운트 cleanup 단계

### 5.6 효과음 명확화를 위한 BGM 사이드체인 더킹 (Ducking)

타격음이 BGM과 동일한 대역에서 겹칠 때 볼륨을 무작정 올리기보다는, 타격음이 발생하는 순간 BGM의 볼륨을 수십 밀리초 동안 살짝 줄였다가(더킹) 천천히 복원시키는 방식을 권장합니다.

```js
export function duckBgm(amount = 0.4, dur = 0.4) {
  const t = c.currentTime;
  duckGain.gain.cancelScheduledValues(t);
  duckGain.gain.setValueAtTime(duckGain.gain.value, t);
  duckGain.gain.linearRampToValueAtTime(1 - amount, t + 0.04); // 서서히 낮춤
  duckGain.gain.exponentialRampToValueAtTime(1, t + dur);      // 자연스럽게 복원
}
```
