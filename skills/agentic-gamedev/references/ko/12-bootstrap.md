## 12. 새 게임 부트스트랩 체크리스트 (복사하여 활용)

```
[ ] data.(js|ts)   — 모든 밸런스 수치를 단일 파일로 구성
[ ] engine.(js|ts) — DOM/렌더러 비의존 pure tick(state, dt) → events[], RNG 주입식 설계
[ ] 시드 RNG (mulberry32) 도입 — 실게임=Math.random / 봇=시드 난수
[ ] render.(js|ts) — state 렌더링 + events 기반 시각 이펙트 (블롭 그림자 포함)
[ ] sfx — tone() + noise() 두 도구 기반, 성공=상승/실패=하강, 히트 레이트리밋(45~70ms)
[ ] music — 스텝 시퀀서 및 상태별 BGM 트랙
[ ] scripts/balance-bot — 가상 플레이어 3종 × N판 시뮬레이션 → 사망 분포 도출
[ ] scripts/baseline.json + `check` 회귀 게이트 구축
[ ] Push-Your-Luck 요소 포함 시 결정점 손익분기 기대값 검사 (3.7)
[ ] 이종 언어/런타임 간 수치 대조 정규식 검사 (2.5)
[ ] 에셋 0개 규칙 검증 테스트 추가 (부록 B)
[ ] window.__game 디버그 훅 + ?rafshim + 고정 타임스텝 + 연출 전용 훅 (9장)
[ ] 게임필: 잔상 체력바, 히트 플래시, 콤보 팝, Floating 데미지 숫자
[ ] 키보드 전 기능 조작 (Enter/Space/Esc/Tab/단축키) + UI 핫키 아이콘 라벨 표기
[ ] 예측형 UI: 유일한 다음 행동 자동 진행, 반복 루프 Enter 1버튼, 되돌리기 동선 차단
[ ] 핵심 스탯 카드 표시 + 호버 툴팁 파생 수치 안내
[ ] 행동 양식을 바꾸는 진화 "잭팟" 특성 최소 1종 탑재
[ ] 사망 시 이월되는 영구 메타 진행 재화 설계
[ ] 자동 품질 조절 (실측 FPS 기반 가벼움 모드 자동 강등)
[ ] 첫 5분 설계: 즉시 시작 버튼 + 1회성 코치 칩 + 핵심 목표 노출 + 결과 PNG 캡처
[ ] CI 스모크 게이트 (첫 방문자 동선 + 콘솔 에러 0, 의도된 404 필터링)
```
