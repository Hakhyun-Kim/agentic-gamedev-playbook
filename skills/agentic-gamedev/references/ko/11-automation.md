## 11. 상시 자동화 — 사람이 자는 동안 백그라운드에서 도는 루프

3장의 밸런스 봇을 일회성 검사 도구에 머무르게 하지 않고 **자동화 스케줄(CI/크론)에 연동**하여 지속적으로 품질을 관리합니다.

| 자동화 루프 | 실행 주기 | 핵심 기능 |
|-------------|-----------|-----------|
| **배포 게이트 스모크** | git push 마다 | 실브라우저 기반 온보딩 동선 + 디버그 훅 검사 (콘솔 에러 감지 시 배포 차단) |
| **야간 밸런스 회귀** | 매일 새벽 | 봇 N판 시뮬레이션 → 사망 분포를 `baseline.json`과 대조하여 이탈 시 이슈 자동 발행 |
| **일일 봇 실주행** ★ | 매일 새벽 | 일일 시드 게임을 봇이 구동하여 시뮬레이션한 플레이 기록을 정적 파일로 생성/커밋 |
| **아침 트렌드 스카우트** | 매일 아침 | 뉴스, 게임잼, 신작 트렌드를 조사하여 3-Gate로 필터링한 상위 3~5개 추천 리스트 생성 |
| **문서 데이터 업데이트** | 주기적 | git 커밋 로그 및 회고 데이터를 분석하여 통계 및 문서 차트를 최신화 |

### 11.1 시뮬레이션 결과물의 게임 콘텐츠화

밸런스 봇의 시뮬레이션 결과(`public/ghost/<날짜>.json`)를 정적 JSON 파일로 커밋해 두면, 서버나 DB 구축 없이도 "오늘 AI 플레이어의 기록"과 경쟁하는 **일일 챌린지 콘텐츠**로 활용할 수 있습니다.

### 11.2 크론 자동화 5대 원칙

1. **멱등성 보장:** "당일 기록이 이미 존재하면 즉시 종료"하도록 설계하여 중복 커밋 차단.
2. **타임존 명시:** 서버의 UTC와 게임 기준 시간대(KST 등)의 불일치 방지.
3. **실패 시 인라인 조용한 폴백:** 봇 구동이 실패하면 빈 정적 파일을 생성하지 않고 이전 폴백 상태 유지.
4. **결과 분리:** 비정상 런타임 종료(exit 1)와 정상적인 밸런스 이탈(exit 2)을 분리하여 후자일 때만 알림 이슈 발행.
