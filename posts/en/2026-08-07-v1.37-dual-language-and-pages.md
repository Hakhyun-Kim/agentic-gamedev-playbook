# v1.37.0 Playbook Dual Language & GitHub Pages Web App

Today we completed a major structural evolution of the **Agentic GameDev Playbook**.

## Key Highlights

1. **Dual Language Architecture (English Main, Korean Secondary)**:
   - Primary reference files reside in `skills/agentic-gamedev/references/en/` compiled to `PLAYBOOK.md`.
   - Secondary reference files reside in `skills/agentic-gamedev/references/ko/` compiled to `PLAYBOOK.ko.md`.
   - All chapter files are kept strictly in sync via automated validation tests.

2. **Refined Writing Tone**:
   - Stripped out monotonous AI-clichés and robotic translationese.
   - Applied concise 1~2 sentence paragraph structures, natural tone, and real developer quotes from actual production logs.

3. **Interactive Web App & Dev Blog**:
   - Built a modern, responsive web application for GitHub Pages.
   - Readers can seamlessly toggle between **📖 Playbook Chapters** and **📰 Daily Dev Logs**, with instant English 🌐 Korean switching.
