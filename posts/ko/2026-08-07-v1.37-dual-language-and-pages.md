# v1.37.0 플레이북 이중 언어 개편 및 GitHub Pages 웹 앱 오픈

플레이북 저장소의 대대적인 구조 개편을 완료했습니다.

## 주요 변경 사항

1. **이중 언어 구조 확립 (영문 메인 / 한국어 서브)**:
   - 영문 원천 문서(`references/en/`)를 메인으로 지정해 `PLAYBOOK.md`를 빌드합니다.
   - 한국어 원천 문서(`references/ko/`)를 서브로 다듬어 `PLAYBOOK.ko.md`를 빌드합니다.
   - `npm test` 시 15개 장 전체의 이중 언어 정합성을 100% 검증합니다.

2. **AI 말투 다듬기 (별도 문체 지침 반영)**:
   - "도입하기에 이르렀습니다", "물러났습니다" 같은 어색한 AI 상투어를 완전히 걷어냈습니다.
   - 1~2문장 중심의 짧고 담백한 문체, 자연스러운 어미 믹스, 개발 당시의 솔직한 생각 따옴표를 적용했습니다.

3. **인터랙티브 웹 앱 & 개발 블로그 구축**:
   - GitHub Pages 전용 모던 웹 앱을 완성했습니다.
   - **📖 플레이북 15개 장**과 **📰 일일 개발 블로그 피드**를 원클릭 EN 🌐 KO 언어 토글로 언제든 읽을 수 있습니다.
